# Документация Mukhomor

Mukhomor — клиент для Windows, который использует mihomo для VPN и отправляет выбранные приложения и сайты напрямую. Сервер нужен свой: приложение не продаёт VPN и не создаёт VPS.

| Получить сервер и настроить протокол | [Свой VPS и VPN](vps-and-vpn.md) |

| Узнать, чья работа используется | [Источники и лицензии](credits.md) |

Документация описывает Mukhomor **0.5.0** с закреплённым **mihomo v1.19.32**. Сайты сторонних проектов могут описывать более новые возможности. [English overview](../README.en.md).
