# Документация Mukhomor

Mukhomor — клиент для Windows, Linux и Android. Он использует mihomo для VPN и отправляет выбранные приложения и сайты напрямую. Для своего VPS нужен клиентский профиль; в 0.8.8 также доступны Tor и внутренняя сеть I2P во вкладке P2P. Приложение не создаёт VPS и не продаёт подписку.
