# Решение проблем

| Симптом | Что проверить |
| --- | --- |
| Импорт отклонён | Совместимость [формата и параметров](protocols.md), UTF-8, лимит текста. Нужен клиентский узел, а не полный Clash/Xray конфиг |
| Вставлен URL подписки, серверы не добавились | Удалённая подписка не скачивается; импортируйте содержимое подписки |
| VPN не подключается | Выбранный профиль, адрес и порт сервера, TLS/SNI/Reality, firewall и поддержка TCP/UDP |
| Обнаружено другое VPN-соединение | Завершите его. Несколько клиентов, меняющих системные маршруты и DNS, могут конфликтовать |
| Игра всё ещё идёт через VPN | Реальное имя процесса / полный путь, сохранение исключений, перезапуск игровых соединений |
| Сайт неожиданно идёт напрямую | Исключение процесса, зоны `.ru`/`.рф`, списки Россия/Steam и порядок [правил](gaming-and-routing.md) |
| «Вернуть домен в VPN» не сработало | Более раннее EXE-правило или пользовательский домен/зона имеют приоритет |
| Голосовая связь не работает через VPN | Поддержка UDP протоколом и сервером; доступность UDP порта |
| qBittorrent не использует прямой маршрут | Внутренняя привязка к VPN-адаптеру и его собственный прокси |
| Закрыл окно, VPN остался | Крестик скрывает в трей. Для отключения используйте кнопку или меню трея |
| После отключения требуется восстановить DNS | Повторите восстановление в приложении; включите отключённый физический адаптер и повторите |
| Новый EXE не запускается из старой папки | Распакуйте новый релиз целиком и запускайте из новой папки |

## Что приложить к Issue

Укажите версию Mukhomor, Windows, тип протокола, ожидаемый результат и шаги воспроизведения. Для проблемы маршрута — имя процесса и обезличенный пример исключения. Скриншот обрежьте так, чтобы не было приватных данных.

**Настройки → Диагностика** содержит локальные сведения о состоянии сети. До публикации просмотрите файл: адреса сервера, локальные пути, имена пользователя/машины и домены могут быть личными. Не прикладывайте исходные конфиги, `private`, ключи, пароли, токены API и ссылки подписок.

Сообщение об уязвимости передавайте по [SECURITY.md](../SECURITY.md). Приложение тестируется на синтетических профилях и loopback-соединениях; работа конкретного VPS, провайдера, античита и реального TUN требует отдельной проверки.
