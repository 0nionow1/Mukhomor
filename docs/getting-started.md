# Начало работы

## Что понадобится

- Windows 10/11 **x64**. Сборок для ARM64, macOS и Linux пока нет.
- Права администратора для первоначальной установки и обновления.
- Собственный серверный профиль или ссылка поддерживаемого протокола. Готовых серверов, подписок и ключей в архиве нет.

## Установка и подключение

1. Откройте [последний релиз](https://github.com/0nionow1/Mukhomor/releases/latest).
2. Скачайте `Mukhomor-X.Y.Z-windows-x64.zip`. Автоматические архивы GitHub **Source code** содержат исходники, а не готовое приложение.
3. Распакуйте **весь** ZIP в отдельную папку. Запускайте `Mukhomor/mukhomor.exe` из распакованного каталога.
4. Подтвердите запрос Windows на установку. Приложение установит компоненты и откроет главное окно. Rust, Node.js и отдельная установка WireGuard не нужны.
5. Нажмите **Добавить конфигурацию**, выберите файл или вставьте ссылку/текст. Можно добавить несколько серверов за одну операцию.
6. Выберите сервер в списке и нажмите **Подключиться**.

Форматы и ограничения перечислены в [руководстве по импорту](protocols.md). URL удалённой подписки не загружается автоматически: сохраните её текст и импортируйте содержимое. Названия серверов на скриншоте — иллюстрация интерфейса, доступ к ним не предоставляется.

EXE пока не подписан сертификатом издателя. При предупреждении Windows сверяйте источник загрузки и SHA256; не отключайте защиту всей системы.

## Проверка SHA256

Рядом с ZIP опубликован одноимённый `.sha256`. В PowerShell вычислите хеш скачанного архива:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Mukhomor-0.5.0-windows-x64.zip'
```

Сравните его с `.sha256` из того же релиза. Хеш обнаруживает повреждение или подмену файла относительно опубликованной суммы; он не заменяет подпись издателя.

## Окно, трей и автоподключение

- **Отключиться** завершает VPN и восстанавливает DNS. Во время запуска кнопка отменяет подключение.
- Крестик скрывает окно в трей: VPN продолжает работать. Нажмите на гриб в трее, чтобы вернуть окно.
- **Выход из Mukhomor** в меню трея отключает VPN, восстанавливает DNS и завершает интерфейс и контроллер.
- Если DNS восстановить не удалось, приложение остаётся открытым и предлагает повторить восстановление.
- **Настройки → Автоподключение** использует последний выбранный сервер после входа в Windows.
- **Настройки → Язык интерфейса**: Авто / Русский / English. Выбор применяется сразу и сохраняется для вашего пользователя Windows.

## Обновление

Скачайте новую версию из [Releases](https://github.com/0nionow1/Mukhomor/releases), отключитесь и завершите приложение через трей. Распакуйте новый ZIP целиком в новую папку и запустите его EXE. Обновление запросит права администратора; профили и настройки остаются в `ProgramData/Mukhomor`. Не переносите отдельный EXE в старую папку: версии компонентов должны совпадать.

Обновления скачиваются вручную. GitHub Releases хранит версии и файлы; автоматического обновления внутри клиента пока нет.

## Где хранятся данные

Установленные компоненты находятся в `%ProgramFiles%\Mukhomor`, профили и рабочие данные — в `%ProgramData%\Mukhomor`. Настройки языка привязаны к пользователю Windows. Профили содержат пароли и закрытые ключи: не прикладывайте каталоги данных к публичным сообщениям.

## Удаление

Отключите VPN и используйте **Параметры Windows → Приложения → Mukhomor → Удалить**. Импортированные профили и настройки сохраняются для повторной установки. Если они больше не нужны, после удаления приложения отдельно удалите `%ProgramData%\Mukhomor`, предварительно сохранив нужные профили в безопасном месте.
