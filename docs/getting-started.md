# Начало работы

## Что понадобится

- Windows 10/11 **x64**, Linux **x64** или Android **8.0+** (ARM64/x86_64). Сборки macOS пока нет.
- Права администратора для первоначальной установки и обновления Windows/Linux. Android использует обычное системное разрешение VPN и не требует root.
- Собственный серверный профиль или ссылка поддерживаемого протокола. Готовых серверов, подписок и ключей в архиве нет.

## Выбор платформы

Откройте [релизы 0.8.2](https://github.com/0nionow1/Mukhomor/releases/tag/v0.8.2) и выберите файл своей системы.

- **Linux:** распакуйте `Mukhomor-0.8.2-linux-x64.tar.gz`, перейдите в каталог пакета, выполните `sudo bash install.sh`, затем запускайте `mukhomor` от обычного пользователя. Требуются совместимая система с glibc 2.35+, X11/Wayland, `zenity` и `setcap`.
- **Android:** установите `Mukhomor-0.8.2-android.apk`, импортируйте профиль через системный выбор документа и разрешите VPN при первом подключении. Фоновое соединение управляется из уведомления.
- **Windows:** используйте ZIP и инструкцию ниже.

Подробные требования, хранение профилей, установка и ограничения: [Windows, Linux и Android](platforms.md).

## Установка и подключение в Windows

1. Откройте [релиз 0.8.2](https://github.com/0nionow1/Mukhomor/releases/tag/v0.8.2).
2. Скачайте `Mukhomor-X.Y.Z-windows-x64.zip`. Автоматические архивы GitHub **Source code** содержат исходники, а не готовое приложение.
3. Распакуйте **весь** ZIP в отдельную папку. Запускайте `Mukhomor/mukhomor.exe` из распакованного каталога.
4. Подтвердите запрос Windows на установку. Приложение установит компоненты и откроет главное окно. Rust, Node.js и отдельная установка WireGuard не нужны.
5. Нажмите **Добавить конфигурацию**, выберите файл или вставьте ссылку/текст. Можно добавить несколько серверов за одну операцию.
6. Выберите сервер в списке и нажмите **Подключиться**.

Форматы и ограничения перечислены в [руководстве по импорту](protocols.md). URL удалённой подписки не загружается автоматически: сохраните её текст и импортируйте содержимое. Названия серверов на скриншоте — иллюстрация интерфейса, доступ к ним не предоставляется.

EXE пока не подписан сертификатом издателя. При предупреждении Windows сверяйте источник загрузки и SHA256; не отключайте защиту всей системы.

## Проверка SHA256

Рядом с ZIP опубликован одноимённый `.sha256`. В PowerShell вычислите хеш скачанного архива:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Mukhomor-0.8.2-windows-x64.zip'
```

Сравните его с `.sha256` из того же релиза. Хеш обнаруживает повреждение или подмену файла относительно опубликованной суммы; он не заменяет подпись издателя.

## Окно, трей и автоподключение

- **Отключиться** завершает VPN и восстанавливает DNS. Во время запуска кнопка отменяет подключение.
- Крестик скрывает окно в трей: VPN продолжает работать. Нажмите на гриб в трее, чтобы вернуть окно.
- **Выход из Mukhomor** в меню трея отключает VPN, восстанавливает DNS и завершает интерфейс и контроллер.
- Если DNS восстановить не удалось, приложение остаётся открытым и предлагает повторить восстановление.
- **Запуск с Windows** и **Автоподключение VPN** — независимые настройки. Автоподключение использует последний успешно подключённый сервер.
- **Настройки → Язык интерфейса**: Авто / Русский / English. Выбор применяется сразу и сохраняется для вашего пользователя Windows.
- **Настройки → Дизайн**: спокойный анимированный фон, сетка между пикселями и ступенчатые скругления. Эффекты можно отключать отдельно. Для старого ПК выключите **Визуальные улучшения**: останется простой пиксельный интерфейс с однотонными поверхностями. Выбор применяется сразу и сохраняется для вашего пользователя Windows.

## Обновление

Скачайте новую версию из [Releases](https://github.com/0nionow1/Mukhomor/releases), отключитесь и завершите приложение через трей. Распакуйте новый ZIP целиком в новую папку и запустите его EXE. Обновление запросит права администратора; профили и настройки остаются в `ProgramData/Mukhomor`. Не переносите отдельный EXE в старую папку: версии компонентов должны совпадать.

Начиная с **0.8.2**, используйте **Настройки → Проверить обновления → Обновить приложение**. Кнопка выбирает опубликованный стабильный релиз для вашей системы, показывает прогресс и проверяет SHA-256 перед установкой. Перед установкой отключите VPN и сохраните изменения. Windows запросит права администратора, Linux — подтверждение через `polkit` (`pkexec`), Android — разрешение устанавливать обновления из Mukhomor и системное подтверждение. Профили, правила и оформление сохраняются. Приложение не устанавливает обновления в фоне без нажатия кнопки.

В опубликованной **0.8.1** кнопки ещё нет: для перехода на версию с обновлением из приложения потребуется один раз установить полный новый пакет вручную. Наличие Slint само по себе не добавляет механизм обновления в уже скачанный файл. Устанавливайте Android APK с тем же ключом подписи; debug-сборка не обновляется выпускным APK поверх существующей установки.

## Где хранятся данные

Установленные компоненты находятся в `%ProgramFiles%\Mukhomor`, профили и рабочие данные — в `%ProgramData%\Mukhomor`. Настройки языка привязаны к пользователю Windows. Профили содержат пароли и закрытые ключи: не прикладывайте каталоги данных к публичным сообщениям.

## Удаление

Отключите VPN и используйте **Параметры Windows → Приложения → Mukhomor → Удалить**. Импортированные профили и настройки сохраняются для повторной установки. Если они больше не нужны, после удаления приложения отдельно удалите `%ProgramData%\Mukhomor`, предварительно сохранив нужные профили в безопасном месте.

## Оформление в 0.7.2

В **Настройки → Оформление** доступны 20 тем и три размера (85%, 100%, 125%): вместе меняются текст, значки и элементы управления с учётом масштаба Windows. Неон — исходная тема. Изменения применяются сразу и сохраняются отдельно от VPN.

Скорость фона регулируется от 25% до 200%; анимацию и остальные эффекты можно отключить. Сброс оформления сохраняет профили и правила. После обновления прежние предпочтения переносятся; для новых готовых правил восстановите нужный шаблон или выполните сброс правил, предварительно экспортировав свои наборы.
