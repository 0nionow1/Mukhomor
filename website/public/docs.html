Windows, Linux и Android

Один интерфейс на Slint, общие темы, импорт профилей и наборы правил. Файлы и статус каждой версии — на странице релизов.

Windows 10/11 · x64

Распакуйте ZIP целиком и запустите Mukhomor/mukhomor.exe. Первая установка запросит права администратора. Пошаговая инструкция — ниже.

Linux · x64

Для Ubuntu 22.04+, Debian 12+ и совместимых систем. Распакуйте .tar.gz, откройте папку пакета и выполните sudo bash install.sh. Запускайте mukhomor от обычного пользователя. Нужны X11 или Wayland, zenity и setcap.

Android 8.0+ · ARM64 / x86_64

Установите APK, добавьте профиль и разрешите VPN при подключении. Root не требуется. Отключение доступно из уведомления. Выпускной APK подписан ключом проекта; обновления должны использовать ту же подпись.

01 / БЫСТРЫЙ СТАРТ

Первое подключение

Поддерживаются Windows 10/11 x64, Linux x64 и Android 8.0+. Для подключения нужен профиль вашего VPN-сервера. Выберите файл своей системы на странице релизов; ниже — установка и различия платформ.

  1. Скачайте приложение

    Откройте страницу релизов → и выберите Mukhomor-X.Y.Z-windows-x64.zip. Архивы «Source code» содержат исходники, а не готовое приложение.

  2. Windows: распакуйте весь архив

    Откройте папку Mukhomor и запустите mukhomor.exe. Подтвердите системный запрос на установку компонентов.

  3. Добавьте свой сервер

    Нажмите «Добавить конфигурацию». Выберите клиентский файл или вставьте ссылку либо текст профиля. Сервер должен быть уже настроен.

  4. Подключитесь

    Выберите сервер в списке и нажмите «Подключиться». При необходимости настройте исключения для игр и приложений в разделе «Правила».

i

Мухомор — клиент. VPS, готовые серверы, ключи и подписки не входят в комплект. Что подготовить на сервере →

Windows предупреждает при запуске

EXE пока без подписи издателя. Скачивайте архив из официального репозитория и сверяйте его SHA256 с файлом .sha256 из того же релиза. Отключать защиту Windows не нужно.

В PowerShell выполните команду, заменив имя файла на имя скачанного архива:

Get-FileHash -Algorithm SHA256 -LiteralPath '.\Mukhomor-X.Y.Z-windows-x64.zip'

02 / СЕРВЕР И ПРОТОКОЛЫ

Свой VPS, свой профиль

VPS — удалённый сервер, который вы арендуете и настраиваете отдельно. Мухомор подключается к работающему на нём VPN.

Что нужно подготовить

  1. Установите на VPS серверное ПО выбранного протокола.
  2. Создайте отдельный клиентский профиль и убедитесь, что нужный порт открыт для TCP и/или UDP.
  3. Перенесите клиентский файл или ссылку в Мухомор. SSH-пароль от VPS в приложении не нужен.

Принимаются клиентские профили, а не произвольные полные конфигурации Clash или Xray. Ссылка на удалённую подписку не скачивается автоматически: сначала сохраните её содержимое, затем импортируйте текст.

Другие протоколы и ограничения

Импорт также поддерживает ShadowsocksR, Hysteria 1, Snell, SOCKS5, HTTP/HTTPS, SSH, AnyTLS, Mieru, TrustTunnel, ShadowQUIC, GOST Relay, Sudoku, MASQUE и ограниченный inline OpenVPN.

Совместимость зависит от параметров профиля, сборки клиента и сервера. Для голосовой связи и других UDP-приложений нужна поддержка UDP с обеих сторон.

Экспериментальный

Mycelia

Наш собственный протокол. Для него нужны совместимые сервер и специальная сборка клиента с поддержкой Mycelia. В стандартной сборке наличие такого адаптера не предполагается.

Используйте профиль, выданный именно вашей серверной сборкой, без ручной замены его полей.

А если нет своего сервера?

Сейчас нужен свой VPS с VPN. P2P и встроенный платный сервис Мухомора находятся в разработке; подключиться через них пока нельзя. Сроки и стоимость сервиса ещё не объявлены.

03 / ИГРЫ И ПРАВИЛА

Каждому — свой маршрут

Игры и выбранные исключения могут идти напрямую, а остальной трафик — через ваш VPN-сервер.

Добавить игру в исключения

  1. Откройте «Правила» и выберите нужный набор.
  2. Добавьте имя исполняемого файла игры, например game.exe, в список прямых исключений приложений. Для Android укажите package ID, например org.example.game. Для Windows и Linux — имя процесса; используйте имя самой игры, а не только лаунчера.
  3. Нажмите «Сохранить» и перезапустите игру, чтобы новые соединения использовали правило.

Также доступны исключения по доменам, доменным зонам и IP/CIDR. Готовые игровые наборы помогут начать; их можно изменить под себя.

i

Прямой маршрут сохраняет обычное соединение с игровым сервером. Пинг зависит от вашего провайдера и маршрута; гарантии его снижения нет. Прямой трафик использует обычный внешний IP вашего подключения.

Собрать набор для себя или друга

В разделе «Наборы» создавайте наборы и включайте их галочкой. Кнопка «+ Готовый» добавляет копию стандартного набора. В разделе «Правила» редактируйте его списки и сохраняйте изменения.

Экспорт JSON содержит правила и описание без серверных ключей и настроек подключения. Импортированный набор сначала выключен: проверьте его содержимое и включите вручную.

Для работы и повседневных задач

Тот же принцип работает для редактора, браузера или рабочего сервиса. Выберите, каким приложениям и доменам нужен прямой маршрут. В исключениях можно указать точный путь к программе.

04 / КАЖДЫЙ ДЕНЬ

Настроить и заниматься своим

Подключение, правила и оформление доступны на всех платформах. Трей и системный запуск зависят от операционной системы.

Окно, трей и фоновая работа

В Windows и Linux с системным треем крестик скрывает окно и сохраняет VPN. В Linux без трея закрытие окна завершает соединение. Android поддерживает VPN в фоне с постоянным уведомлением. Кнопка «Отключиться» завершает соединение и восстанавливает DNS.

Чтобы завершить приложение полностью, выберите «Выход из Mukhomor» в меню трея.

Автозапуск и автоподключение

Это два отдельных переключателя в настройках. «Запуск с Windows» открывает клиент в трее после входа. «Автоподключение VPN» подключает последний успешно использованный сервер. Для обоих действий включите оба параметра.

Оформление

Откройте «Настройки → Оформление»: доступны 20 тем и размеры интерфейса 85%, 100% и 125%. Эффекты можно отключить. Сброс оформления сохраняет серверы и правила.

Обновление

Скачайте файл своей платформы со страницы релизов. В Windows завершите клиент через трей и распакуйте весь архив в новую папку. В Linux отключите VPN и повторите установку. На Android установите APK с совместимой подписью. Обновления скачиваются вручную; перед сменой подписи Android сохраните важные данные.

Удаление

Отключите VPN и откройте «Параметры Windows → Приложения → Mukhomor → Удалить». Профили и настройки сохраняются для повторной установки.

05 / ЕСЛИ ЧТО-ТО НЕ ТАК

Проверим по порядку

Несколько коротких ответов на частые вопросы.

Не получается подключиться

Проверьте, что сервер работает, выбран нужный профиль, совпадают адрес, порт и параметры протокола. На VPS должны быть разрешены необходимые TCP/UDP-порты.

Завершите соединение другого VPN-клиента: несколько программ могут одновременно менять маршруты и DNS.

Конфигурация не импортируется

Нужен клиентский профиль поддерживаемого формата. Полный серверный конфиг, резервная копия другого приложения и URL удалённой подписки не заменяют его. Проверьте кодировку UTF-8 и параметры выбранного протокола.

Посмотреть форматы импорта →
Игра всё ещё использует VPN

Проверьте имя игрового процесса или его полный путь, включите нужный набор и сохраните правила. Затем перезапустите игру: уже установленные соединения могут сохранять прежний маршрут.

Не работает голосовая связь

Проверьте поддержку UDP протоколом и сервером, а также доступность UDP-порта. Проверьте правило маршрута для приложения голосовой связи.

Закрыл окно, но VPN остался включён

Это работа в трее. Откройте клиент через значок гриба и нажмите «Отключиться» или выберите «Выход из Mukhomor» в меню трея.

После отключения нужно восстановить DNS

Повторите восстановление в приложении. Если физический сетевой адаптер отключён, включите его и попробуйте ещё раз.

Нужна помощь с ошибкой?

Опишите версию Мухомора и вашей ОС, протокол и шаги, после которых появляется проблема. Не публикуйте рабочие профили, ключи и ссылки подписок.
