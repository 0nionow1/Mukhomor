О ПРИЛОЖЕНИИ

Вопросы и ответы

Что такое Мухомор?

Мухомор (Mukhomor) — VPN-клиент с открытым исходным кодом для Windows, Linux и Android. Общий интерфейс на Slint подключается к вашему VPN-серверу и позволяет выбирать прямые маршруты для приложений, доменов и IP.

Что нужно для подключения?

Windows 10/11 x64, Linux x64 с glibc 2.38+ или Android 8.0+. Для своего VPS добавьте клиентский профиль. В 0.8.8 также можно выбрать Tor или внутреннюю сеть I2P во вкладке P2P. В Linux для установки нужны права администратора, в Android — системное разрешение на VPN. Серверы и ключи в комплект не входят.

Чем Мухомор удобен для игр?

Игры можно оставить на прямом соединении, а браузер и другие приложения направить через VPN. Есть готовые игровые исключения и свои наборы правил. Пинг зависит от провайдера и маршрута; снижение пинга не гарантируется.

Подходит ли приложение для работы?

Да. Правила можно настроить для браузера, редактора, IDE и рабочих сервисов. Есть обмен наборами правил. Windows и Linux поддерживают системный трей и автозапуск; Android сохраняет подключение в фоне с уведомлением.

Что такое Mycelia?

Mycelia — собственный экспериментальный протокол проекта. Для него нужны совместимый сервер и специальная сборка клиента. Поддержка зависит от выбранной сборки; стандартный клиент также импортирует профили других поддерживаемых протоколов.

Можно подключиться через P2P или встроенный сервис?

В 0.8.8 во вкладке P2P доступны Tor с мостами и готовыми пресетами Snowflake, а также I2P только для внутренних сайтов .i2p. Аккаунт и оплата не нужны; UDP приложений недоступен, доступность зависит от сети. Новый выпуск находится в проверке. Встроенный платный сервис пока в разработке.

Как обновить приложение?

Откройте Настройки → Проверить обновления → Обновить приложение. Загрузка проверяется по SHA-256; профили и настройки сохраняются. Перед установкой отключите VPN и сохраните изменения. Windows и Linux запрашивают права администратора, Android — системное подтверждение. После переименования аккаунта GitHub прежним версиям может потребоваться ручная установка 0.8.8 со страницы релизов.
