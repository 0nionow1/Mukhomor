# Участие в Mukhomor

Для ошибки используйте [Issues](https://github.com/0nionow1/Mukhomor/issues): версия приложения и Windows, протокол, шаги воспроизведения, ожидаемое и фактическое поведение. Никогда не прикладывайте рабочие VPN-профили, ссылки подписок, приватные ключи или полную диагностику без просмотра. Для уязвимостей: [SECURITY.md](SECURITY.md).

Для изменения создайте ветку и Pull Request. Опишите проблему, получившееся поведение и выполненные проверки. Сборка и тесты описаны в [development.md](docs/development.md).

- Сохраняйте разделение UI, контроллера, импорта, правил и операций Windows.
- Ограничивайте ввод и выполнение внешних операций; не добавляйте выполнение кода из профиля.
- Используйте синтетические значения и loopback для тестов.
- Обновляйте русский и английский интерфейс для новых строк.
- Новые публичные файлы добавляйте в `.gitignore` и список упаковки `Build-Release.ps1`, затем запускайте `Test-PublicSource` и проверки релиза.
- Сохраняйте upstream атрибуцию и тексты лицензий.

Собственные изменения публикуются под [MIT](LICENSE); лицензии сторонних компонентов остаются отдельными. Перед PR проверьте staged diff и отсутствие локальных данных. Доступ к вашему серверу для воспроизведения ошибки не требуется.
