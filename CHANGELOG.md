## [0.5.0] — 2026-10-09

Первый публичный выпуск Mukhomor для Windows 10/11 x64.

- Нативный Rust/Win32 интерфейс с пиксельным грибом, треем и русским/английским языком.
- Разделение TCP/UDP трафика по приложениям, доменам, зонам и IP/CIDR; готовые исключения для игр, qBittorrent, российских сервисов и Steam.
- Локальный импорт 21 типа узлов: WireGuard/AmneziaWG, VLESS, VMess, Trojan, Shadowsocks/SSR, Hysteria 1/2, TUIC, Snell, SOCKS5, HTTP/HTTPS, SSH, AnyTLS, Mieru, TrustTunnel, ShadowQUIC, GOST Relay, Sudoku, MASQUE и OpenVPN.
- Проверка всей пачки импортируемых серверов до изменения библиотеки; ограниченные JSON/YAML и inline `.ovpn`.
- Отмена подключения, восстановление DNS, автоподключение и установка обновлений с сохранением профилей.
- Нативные наборы mihomo для больших пользовательских исключений; необязательное обновление IP через DNS API.
- Руководства для пользователей, настройки VPS, протоколов, разработки и релизов; CI и проверка состава публикации.

**Компоненты:** mihomo v1.19.32, Wintun 0.14.1, Tiny5 Regular. **Ограничения:** EXE без подписи издателя; удалённые подписки не скачиваются автоматически; UDP зависит от сервера/протокола; автоматического обновления клиента нет.

**Скачивание:** `Mukhomor-0.5.0-windows-x64.zip`. Распакуйте весь архив и запустите `Mukhomor/mukhomor.exe`. Серверные реквизиты не входят в поставку. Для исходников — `Mukhomor-0.5.0-source.zip`, для проверки файлов — соответствующие `.sha256`.
