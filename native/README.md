# Mukhomor native

Rust/Win32 event-driven GUI and local controller. Build from the project root with Build-Release.ps1. The compiled palette and mushroom icon come from assets/theme.json. Tiny5 Regular is embedded and registered privately for the GUI lifetime; see assets/fonts/README.md and Tiny5-LICENSE.txt in the project root. Pixel geometry and buffered GDI painting avoid a continuous rendering loop. See ../README.md for setup, isolation and verification.

ProfileImport.psm1 normalizes local share links, base64 link lists, standalone JSON/YAML nodes, legacy WireGuard/AmneziaWG files and a strict inline OpenVPN subset. A batch is parsed and checked by the pinned core before the library changes. Library schema 1 retains legacy .conf entries; new entries use a private JSON envelope and expose only id/name/protocol over IPC. All protocols share the existing AWG proxy alias and split rules. Non-WireGuard endpoints retain their hostname for TLS/SNI/Reality and bind to the physical interface; endpoint A/AAAA addresses are excluded from TUN routes. The import form uses a native EDIT control, not a browser or clipboard poller. The title displays the compiled Cargo version.

build.rs bakes domain-warped gradient Perlin noise into one large 8-bit indexed field with zinc low regions and indigo peaks. Teal is reserved for the logo and controls. The default 10-pixel logical grain, 480-pixel flow scale and 16 color levels give crisp contours across enlarged organic forms. Default area thresholds target approximately 58% zinc and 42% indigo regions in the standard Home crop; visible coverage varies with height and integer DPI scaling. texture.rs caches five small indexed DIBs/DCs plus solid brushes through RAII. [StretchBlt](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-stretchblt) projects only the visible source cells at an integer scale with COLORONCOLOR; DPI changes allocate nothing. The application generates no runtime noise or texture pixels. Tests compare actual GDI pixels, child origins and viewport clipping with baked samples, verify area coverage and nonrepeating flow, and check handle identities through repeated DPI cycles.

The controller reads one bounded UTF-8 JSON reply terminated by a newline from NativeBridge.ps1. A successful core remains a live descendant of the helper, so the reply boundary must not depend on stdout reaching EOF. Helper exit, cancellation and operation deadlines remain supervised separately. Windows documents the inherited-pipe behavior in [Pipe Handle Inheritance](https://learn.microsoft.com/en-us/windows/win32/ipc/pipe-handle-inheritance).

Fresh Connect, Select and Update actions clear a completed cancellation only while holding the connection-intent lock and matching its generation. A newer Disconnect or Exit retains priority, including during a queued selection or rule update. Test-Disconnect.ps1 -CancellationOnly exercises repeated cancel/select/reconnect cycles with isolated helpers.

Custom domain lists of 32 or more entries compile into Mihomo's native immutable domain set; exact entries and +.suffix entries preserve their original DIRECT priority. Custom IP lists of 32 or more entries use the native merged IPv4/IPv6 set with domain resolution retained. Inline payloads belong to the validated candidate, including rollback. Socket attribution is strict when EXE rules exist and off otherwise. ApplySettings validates once, and its response reuses the validated settings. Scalar-array copies retain empty/single/nested JSON array shapes without a per-item PowerShell pipeline. API probes parse only the controller settings. Test-LargeRules.ps1 and the maximum-list IPC regression cover this behavior; Measure-Routing.ps1 reports a loopback comparison with raw samples and explicit measurement limits.

The mushroom button paints into a reusable child buffer and presents one clipped BitBlt per frame. Its pulse changes only the palette. Native edit controls retain their original caret, selection and scrolling behavior; multiline formatting rectangles add padding, while single-line fields center visible Tiny5 glyphs within the original hit area.
