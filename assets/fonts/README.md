# Tiny5

Unmodified Tiny5 Regular by Stefan Schmidt / The Tiny5 Project Authors.
Latin, Greek, Cyrillic and extended Cyrillic. SIL Open Font License 1.1;
the complete copyright and license are in `../../Tiny5-LICENSE.txt`.

Official source: https://github.com/google/fonts/tree/b2723573ff4dd21b37158d1d549269e21a559df9/ofl/tiny5

- File: `Tiny5-Regular.ttf` (132124 bytes)
- SHA256: `cb8168f80cfee2f47f6db59f2a7afbde31cdcdcdcf262e7a993e4d468a5bf4b0`
- Upstream: https://github.com/Gissio/font_tiny5

The font is embedded into the GUI executable and registered privately for its
lifetime. It is never installed in Windows or downloaded when the app runs.
Native pixel text uses regular weight and disables antialiasing.
