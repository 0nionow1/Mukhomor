# Краткое руководство

[Первый запуск](../docs/getting-started.md) · [Игры и правила](../docs/gaming-and-routing.md) · [Протоколы](../docs/protocols.md) · [Решение проблем](../docs/troubleshooting.md)

Распакуйте весь архив и запустите `mukhomor.exe` из папки Mukhomor. Добавьте собственный серверный профиль и выберите подключение. Профили, серверы и ключи не входят в комплект.

В версии 0.7.2 раздел **Настройки → Оформление** предлагает 20 тем и три размера интерфейса. **Наборы** управляют готовыми и пользовательскими наборами, **Правила** редактируют их содержимое.

Для обновления также распакуйте весь новый пакет; приложение сохранит существующие профили и правила. [Все изменения после 0.5.0](../CHANGELOG.md).
